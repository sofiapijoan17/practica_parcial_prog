# Modelo Parcial 1 - Programacion II - 2025

## Indicaciones generales

1. Debes completar el examen en un máximo de 120 minutos.
2. Podés utilizar cualquier libro, recurso en línea o código antiguo durante este examen, pero no puedes comunicarte con ninguna persona que no sean tus docentes (en linea y en el aula).
3. Debes usar las funciones que vimos en clase, en el libro de la materia y en los ejercicios hasta la ultima leccion, siguiendo los consejos vistos en clase.
4. Este examen parcial consta de varias tareas que debes completar. Cada tarea se describe en un chunk de código separado. Debes completar cada tarea en el chunk correspondiente.

## Instrucciones para trabajar

1. Vamos a utilizar GitHub para manejar el examen. Por favor, cloná este repositorio siguiendo las instrucciones que dejamos en el campus para comenzar a trabajar.
2. Abrí el proyecto de RStudio y luego el archivo **.Rmd** contenido en el proyecto. 
3. Cuando termines, tendrás que hacer commit y push para que tus cambios sean enviados a GitHub Classroom.
4. Copiá el SHA del commit y envialo a través del campus siguiendo las instrucciones que dejamos ahí.
